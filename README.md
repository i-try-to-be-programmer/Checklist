# Checklist
Чек-лист составленный в ходе прохождения курса "Тестирование ПО с нуля. Теория + практика. Продвинутый курс с ИИ"


Чек лист был составлен по следующим пользовательским историям (USER STORY):

ID1 Регистрация пользователя / User Registration

ID2 Вход в систему / User Login

ID3 Выход из системы / User Logout

ID4 Проверка авторизации перед доступом к функциональности / Authorization Check before Accessing Functionality

ID5 Просмотр списка товаров и деталей продукта / Viewing the product list and product details

ID6 Добавление товара в корзину / Adding a product to the cart

ID7 Фильтрация списка товаров / Filtering the product list

ID8 Сортировка списка товаров / Sorting the product list
